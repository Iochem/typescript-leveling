# Mini Project - Time Duration Analyzer

#### 📌Difficulty : Advanced

## 🚀Features
- Explicit domain modeling with union types
- Snapshot-based process state tracking
- Transition detection (ON, OFF)
- Downtime duration calculation and formatting
- Severity classification (HEALTHY, DEGRADED, CRITICAL)
- Deterministic in-memory evaluation with no persistence

- *Classes*
